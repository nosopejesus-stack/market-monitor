# proyecto-nuevo

Proyecto desde cero, con **memoria en Obsidian** y **agentes que aprenden y ayudan**.

| Carpeta | Para qué |
|---|---|
| `vault/` | Vault de Obsidian: inicio, visión, aprendizajes, decisiones, diario, agentes, plantillas |
| `src/` | Código del proyecto |
| `tests/` | Tests |
| `../.claude/agents/` | Agentes: `bibliotecario`, `investigador`, `revisor` |

## Abrir el vault en tu PC
1. Clona el repo (o `git pull`).
2. En Obsidian: *Abrir carpeta como vault* → `proyecto-nuevo/vault`.
3. Recomendado: plugin comunitario **Obsidian Git** para sincronizar automáticamente con GitHub.

## Ciclo de trabajo
Leer memoria (bibliotecario) → investigar (investigador) → construir → revisar (revisor) →
guardar lo aprendido (bibliotecario) → commit + push.
